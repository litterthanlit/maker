02 — Proportions

A tall x-height on a 1000-unit em.

Lowercase stands at 528 units against 720 for capitals, close to the classic Swiss ratio. Round letters overshoot each line by 12 units so they look the same height as the flat ones.

06 — Character

What it keeps from the Swiss grotesque, and what it changes.

ces

Horizontal terminals

Curves end in flat, level cuts, which closes the apertures and keeps lines of text calm.

oO0

Squarish rounds

Bowls are superellipses, not circles, so rounds sit comfortably beside straight stems.

xH

Tall x-height

Lowercase reaches 73% of cap height, so small sizes stay legible.

Its own details

RG

Straight R leg, spurless G

A diagonal R leg and a G whose bar meets a short vertical, with no spur.

aty

No tails

Flat-footed a, a flat-topped t, and a straight y descender give a more constructed feel.

ij!

Square dots

Dots and full stops are true squares that grow with the stem weight.

07 — Use it

Load one variable file.

The variable WOFF2 covers every weight. Static TTF and WOFF2 files are in the repository too, for apps that don't support variable fonts.

@font-face {
  font-family: "Kanton Grotesk";
  src: url("KantonGrotesk[wght].woff2") format("woff2");
  font-weight: 300 700;
  font-display: swap;
}

body { font-family: "Kanton Grotesk", "Helvetica Neue", Arial, sans-serif; }
h1   { font-weight: 650; letter-spacing: -0.02em; }
