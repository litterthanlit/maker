Its own face

Laid over Geist

Geist was a yardstick for overall width and spacing, never a source: every outline is drawn by Litt's own code. Laid over Geist at the same size, the shared shape is just what any grotesque shares. The details part ways: horizontal cuts, squarer rounds, a flat-footed a, a straight-legged R and y, square dots, and figures with their own flag, stem and tail.

Use it

One line in a project

Every world reads --font-choice first, so this takes over Press and Flat with no change to litt. Nothing needs turning on: the font has no stylistic sets, as litt asks. Device keeps Geist Mono.

@font-face {
  font-family: "Litt Grotesk";
  src: url("/fonts/LittGrotesk[wght].woff2") format("woff2");
  font-weight: 400 600;
  font-display: swap;
}

:root { --font-choice: "Litt Grotesk"; }
[data-material="device"] { --font-choice: initial; }
370 characters: Latin-1 and Latin Extended-A, UI punctuation, currency, arrows and math. Variable 300 to 700, 30 KB as WOFF2. Comparisons render live in your browser with Inter and Geist embedded.
