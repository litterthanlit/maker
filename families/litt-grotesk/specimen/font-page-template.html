InstallWOFF2 · TTF · variable

Use it in CSS

One variable file covers every weight. Declare it once, then set weight anywhere from 300 to 700.

Variable, webfonts/variable/LittGrotesk[wght].woff2
Variable, desktopfonts/variable/LittGrotesk[wght].ttf
Static, 5 weightsfonts/static/LittGrotesk-*.woff2

In the litterthanlit/maker repository.

@font-face {
  font-family: "Litt Grotesk";
  src: url("/fonts/LittGrotesk[wght].woff2") format("woff2");
  font-weight: 300 700;
  font-display: swap;
}

body {
  font-family: "Litt Grotesk", "Helvetica Neue", Arial, sans-serif;
}

/* numbers in tables and counters */
.value { font-variant-numeric: tabular-nums; }
// app/layout.tsx (Next.js)
import localFont from "next/font/local";

const litt = localFont({
  src: "./fonts/LittGrotesk[wght].woff2",
  weight: "300 700",
  variable: "--font-litt",
});
AboutFONTLOG.md

Drawn in code

Every letter is generated from parameters in Python: stems, arches and widths come from one set of numbers per weight, so Light and Bold stay the same design.

Built on Archivo

The figures, symbols, and a, s and S come from Archivo by Omnibus-Type (OFL), fitted so their strokes match Litt's at every weight.
